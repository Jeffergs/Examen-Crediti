# 🗺️ Roadmap

## 🎯 Objetivo

Este documento apresenta o planejamento evolutivo do **Examen Crediti**, descrevendo as principais etapas de desenvolvimento, a evolução das versões e os grandes marcos técnicos do projeto.

O roadmap tem como objetivo orientar a evolução do sistema e facilitar o acompanhamento do progresso ao longo do desenvolvimento.

## 🚀 Estratégia de Desenvolvimento

O Examen Crediti será desenvolvido de forma incremental.

Cada versão entregará um conjunto de funcionalidades juntamente com a evolução da arquitetura, da infraestrutura e das práticas de engenharia de software.

Os detalhes das funcionalidades serão documentados em **03-requisitos-funcionais.md**.

## 📅 Fases do Projeto

### 🟡 Fase 1 — Fundação (v0.1.0)

**Objetivo**

Preparar toda a estrutura do projeto.

**Escopo**

- Estrutura do repositório
- Padronização do projeto
- Documentação
- Configuração inicial do ambiente
- Organização dos microsserviços

**Principais Tecnologias**

- Git
- GitHub
- Java
- Maven
- Spring Boot

**Status**

🟡 Em andamento

---

### ⚪ Fase 2 — Primeira Entrega Funcional (v0.2.0)

**Objetivo**

Implementar a primeira versão funcional do sistema.

**Escopo**

- Implementação dos primeiros microsserviços
- Persistência de dados
- APIs REST
- Validações
- Testes unitários

**Principais Tecnologias**

- Spring Boot
- Spring Web
- Spring Data JPA
- PostgreSQL
- JUnit
- Mockito

⚪ Não iniciada
